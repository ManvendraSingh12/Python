## **Project Title: Digital Diary / Notes Manager** :-->

The Digital Diary / Notes Manager is a simple console-based application made using Python 3. It helps users save and manage their daily notes easily through a menu.

The project has the following features:
1. Add Notes: Users can add notes with a date in YYYY-MM-DD format.
2. View Notes: Users can see all their saved notes with serial numbers.
3. Search Notes: Users can search for notes using keywords. The search is not case-sensitive.
4. Delete Notes: Users can delete any note by entering its serial number.
5. Save Notes: All notes are stored in a file named diary.txt, so they are not lost after closing the program.


## **Technologies Used** :-->
- Python 3
- Regular Expressions
- File Handling
- Lists and Functions
- Loops and Conditional Statements


## **Objective** :-->

> The main aim of this project is to create a simple digital diary where users can easily add, view, search, and delete their daily notes.



## **Conclusion** :-->

> This project helps students understand basic Python programming concepts and learn how to store and manage data using file handling.
