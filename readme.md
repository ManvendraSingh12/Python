## **Digital Diary / Notes Manager** :-->


Introduction:
Digital Diary is a simple Python project that helps users write and save their daily notes. Users can easily add, view, search, and delete notes.

Features
1. Add new notes.
2. View all saved notes.
3. Search notes by keyword.
4. Delete unwanted notes.


Requirements:
- Python 3
- Computer or laptop
- Any Python code editor


How to Run:
1. Install Python 3.
2. Save the program as diary.py.
3. Open the terminal.
4. Type python diary.py and press Enter.


Files Used:
- diary.py – Main program.
- diary.txt – Stores the notes.


Concepts Used:
- File Handling
- String Methods
- Regular Expressions
- Exception Handling


Conclusion:
This project is useful for saving daily notes. It is easy to use and helps students learn basic Python programming and file handling.
